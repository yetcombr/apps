# yet apps

The desktop app of [yet](https://yet.com.br) — every workspace in one window,
with notifications, and calls with your camera, microphone and screen.

## Download

**[Latest release →](https://github.com/yetcombr/apps/releases/latest)**

| system | file |
| --- | --- |
| macOS, Apple silicon (M1 and later) | `yet-<version>-arm64.dmg` |
| macOS, Intel | `yet-<version>.dmg` |
| Windows | `yet-Setup-<version>.exe` |
| Linux | `yet-<version>.AppImage` (updates itself) or `.deb` |

Once installed, the app keeps itself up to date.

---

This repository only holds the releases. The app is built from the `desktop/`
folder of yet's own repository, and published here on every desktop release.
